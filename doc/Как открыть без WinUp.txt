КАК ОТКРЫТЬ ПАКЕТ БЕЗ WINUP

Формат: обычный архив tar, зашифрованный стандартным age с паролем. WinUp для открытия не обязателен. Нужны сам пакет, его пароль, age и программа для распаковки tar.

WINDOWS — ПО ШАГАМ
1. Создайте новую пустую папку для расшифровки и скопируйте в неё пакет. Оригинал сохраните.
2. Установите официальный age: откройте PowerShell и выполните:
   winget install --id FiloSottile.age --exact
   Затем откройте PowerShell заново. Без WinGet скачайте ZIP windows-amd64 с https://github.com/FiloSottile/age/releases и распакуйте его. Если age.exe лежит рядом с пакетом, вместо age в команде используйте .\age.exe.
3. В Проводнике откройте созданную папку, нажмите адресную строку, введите powershell и нажмите Enter. Выполните:
   age --decrypt --output 'Расшифровано.tar' 'Пакет.tar.age'
   Если пакет переименован, подставьте его настоящее имя вместо имени в последней части команды. age сам попросит пароль. Введите пароль пакета; символы могут не отображаться. Пароль в команду вставлять не нужно.
4. Только если age завершился без ошибки, распакуйте результат:
   New-Item -ItemType Directory -Path 'Открыто' -ErrorAction Stop
   tar -xf 'Расшифровано.tar' -C 'Открыто'
   Файлы находятся в папке Открыто. Архив tar можно также открыть установленным архиватором с поддержкой tar.

Если имена Расшифровано.tar или Открыто уже заняты, начните в другой новой пустой папке. Если age сообщает об ошибке пароля или повреждении, не распаковывайте промежуточный tar.

macOS / LINUX
Установите официальный age для своей ОС, выполните age --decrypt --output Расшифровано.tar Пакет.tar.age, затем распакуйте tar в новую пустую папку. Пробелы в именах заключайте в кавычки.

В архиве есть служебный .winup-package.json. Это список содержимого и меток загрузки, а не пароль. Обычные age/tar возвращают файлы и папки, но не восстанавливают эти метки NTFS автоматически; WinUp восстанавливает их при своей расшифровке. Не передавайте расшифрованный tar как зашифрованный файл: пароль уже снят.

Для открытия через WinUp: Файлы → Расшифровать пакет…, выберите пакет, новую папку и введите пароль.

КАК ОТКРЫТЬ ХРАНИЛИЩЕ БЕЗ WINUP

Хранилище использует формат Cryptomator 8. Его открывает обычный Cryptomator Desktop. Это другой формат, чем отдельный пакет tar.age.

1. Закройте хранилище в WinUp. Для переноса используйте всю папку хранилища либо резерв из команды Резерв / перенос…. Нужны vault.cryptomator, masterkey.cryptomator и каталог d целиком. Один зашифрованный файл из каталога d открыть отдельно нельзя.
2. Установите Cryptomator с https://cryptomator.org/downloads/.
3. Нажмите Добавить хранилище / Add Vault → Открыть существующее / Open Existing Vault. Выберите vault.cryptomator; если диалог просит masterkey.cryptomator, выберите этот файл в той же папке. Создавать новое хранилище поверх прежнего не нужно.
4. Нажмите Разблокировать / Unlock и введите пароль именно файлового хранилища. Пароль базы паролей WinUp и пароль отдельного пакета могут отличаться.
5. Нажмите Показать диск / Reveal Drive. На открытом диске можно читать, копировать и редактировать файлы. После работы закройте документы и заблокируйте хранилище в Cryptomator.

Не открывайте одну и ту же папку одновременно в WinUp и Cryptomator. История WinUp может отображаться как служебная папка .winup-history; не удаляйте её, если нужны прежние версии. Настройки редактора и буквы диска WinUp в Cryptomator не переносятся.

Для возвращения в WinUp: Файлы → Добавить существующее, выберите папку хранилища и откройте прежним паролем.
