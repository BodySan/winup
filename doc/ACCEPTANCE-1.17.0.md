# Приёмка WinUp 1.17.0

Дата: 9 октября 2026. Проверяются семь функций из согласованного списка «сейчас».
Все базы, пароли, ключи и файлы проверок искусственные; личная база не открывается.

## Автоматические функциональные проверки

`qa/security/FileWorkflowProbe.cs`: 117 успешных проверок, 0 отказов в Windows Sandbox.
Проверяются реальные KeePassLib и CryptoFS/Cryptolib, сохранение и повторное открытие,
история/корзина и связанные записи, режимы файлов, отмена правок, форматы экспорта и импорта.
Отдельно моделируется отказ сохранения при занятом файле базы и блокировка во время окна ошибки:
правки поля и массовые правки не возвращают секреты в закрытую базу, исходный файл не меняется.
Умышленно неполная структура учебного хранилища обнаружена штатным HealthCheck и не исправлена.

`SecurityHarness --functional-only`: `TOTAL failures=0`. Это регрессии функционала,
а не возобновление отложенного аудита безопасности.

Проверка интерфейса: восемь вкладок, размеры 700×550 и 1080×760,
146 размещений действий доступны, список и панели не вытесняются за границы окна.

## Независимая совместимость ключа Cryptomator

Неизменённые `RecoveryKeyFactory.java`, `WordEncoder.java` и словарь из Cryptomator 1.19.3
скомпилированы отдельно от адаптера. Для компиляции добавлены только определения
неисполняемых аннотаций JetBrains и константы имён файлов; код алгоритма не менялся.
200 случайных исходных ключей: все последовательности из 44 слов совпали с WinUp;
штатная проверка, расширенная проверка исходных байтов и обратное чтение успешны.
Оригинальные исходники и их SHA-256 включены в публичный пакет.

## Пользовательские сценарии

В настоящих окнах учебной WinUp через оконный драйвер нажимаются кнопки,
выбираются строки и столбцы, заполняются диалоги и проверяются результаты:

- Поле: добавить → скопировать → сохранить → удалить/отменить → проверить сохранность → изменить/сохранить.
- Две отмеченные записи: общая категория → сохранение → обновлённый список; остальные параметры остаются прежними.
- История: выбрать → посмотреть → показать/скопировать старый секрет → восстановить с подтверждением.
- Корзина: удалить → найти → восстановить → увидеть запись в действующем списке.
- Файлы: получить ключ при открытом хранилище → безопасное закрытие → копирование 44 слов.
- Файлы: сменить пароль → проверить структуру новым паролем → скопировать отчёт → сбросить пароль прежним ключом → повторно открыть прежние файлы.
- Импорт: JSON Bitwarden → просмотр пропусков → сохранить → повторить и увидеть дубль → отменить.
- Импорт: CSV с точкой с запятой → назначить три столбца → просмотр → сохранить → открыть дополнительное поле.

Инструкция содержит 47 снимков учебной копии. Все изображения и внутренние якоря
проверяются браузером; проверяются отображение на широком/узком экране и копируемые адреса браузеров.

Подписанный выпуск допускается к установке после успешного CI и проверки цикла обновления:
проверка подписи → подготовка → перезапуск → применение → повторная проверка версий.
Перед заменой установленной программы сохраняется полная копия данных; после замены
контрольные суммы исходных пользовательских файлов должны совпасть.
