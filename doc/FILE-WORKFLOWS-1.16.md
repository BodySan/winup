# Функциональная приёмка WinUp 1.16.0

Проверки выполняются в Windows Sandbox на искусственных аккаунтах, файлах и хранилищах C:\WinUpAudit. Личная база владельца не открывается. Это проверка функций; отложенный аудит безопасности не выполнялся.

## Файлы и импорт: 55 PASS, 0 FAIL

FileWorkflowProbe проверяет настоящие адаптеры Cryptomator, WinFsp и age, а не заглушки:

- CSV Google: кавычки, запятые, многострочная заметка, точный повтор и другой пароль аккаунта. CSV Apple: привязка OTPAuth. Неполная строка отклоняется.
- Пакет: формат age, Unicode, пустые папки, файл 64 МиБ, полное чтение, неправильный пароль, оборванный пакет, занятое имя результата и отмена. Исходники сохраняются при отказе; перенос удаляет их после проверки.
- Длинный путь исходника и длинные имена зашифрованной резервной копии.
- Создание пакета при открытом хранилище. Выгрузка выбранного файла с подключённого диска и сохранение Zone.Identifier; лишние файлы в результат не попадают.
- История: отсутствие лишнего повторного снимка, новая версия после изменения, удаление, восстановление содержимого и метки скачивания, отказ замены существующего файла, лимит версий.
- Занятый файл мешает закрытию, диск продолжает работать. После освобождения безопасное отключение проходит.
- Резерв: проверка контрольных сумм, фактическое открытие копии прежним паролем, чтение восстановленного файла, повторный резерв копии.
- Режим чтения: чтение через диск разрешено, запись через WinUp и Проводник отклоняется, отключение проходит.
- Настройки проекта сохраняются. Закрепление и категории сохраняются в KDBX и после нового открытия. Поиск сочетается с категориями и закреплением. Подсказка распознаёт импортированный аккаунт по адресу страницы входа шаблона.
- Блокировка базы оставляет файловый диск; блокировка файлов оставляет базу; общая блокировка закрывает оба.

## Проверка живого интерфейса

Проверены фильтр категории «Игры», переключатель закреплённых, применение шаблона Steam с подсказкой существующего аккаунта, открытие истории и настроек проекта. Через кнопку импорта CSV добавлен другой учебный Google-аккаунт; конфликт пароля Steam остался невыбранным. Существующие записи сохранились.

При создании пакета через системные окна найдены и исправлены отказ при открытом хранилище и повторное расширение имени. Повторная проверка кнопками прошла: пакет создан под выбранным именем при открытом хранилище, исходник сохранён. При выходе найдена и исправлена попытка обновления уже удалённого значка трея; учебное приложение затем завершилось с кодом 0.
