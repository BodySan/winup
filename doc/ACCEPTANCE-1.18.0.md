# Проверка WinUp 1.18.0

## Подтверждено

- 46 сценариев расширенного автоввода, групп, меток, вложений, ссылок между полями, объединения баз и восстановления копии хранилища. Проверялся фактический ввод в учебное приложение, включая переключение окна, блокировку базы и изменение записи во время ввода. Импорт сравнивает связанные логины и пароли; недоступная ссылка требует выбора для соответствующей строки, остальные записи продолжают обрабатываться. Связанный логин отображается в списке и участвует в поиске; удаление основной записи не нарушает работу списка.
- 117 файловых сценариев: шифрование и расшифровка, перенос и копирование, работа через подключённый диск, история, резерв, смена пароля, восстановление и диагностика.
- Доступность 160 действий в восьми вкладках при двух размерах окна; 13 новых окон и учебных снимков интерфейса.
- По 23 сценария расширения в Chrome, Edge, Firefox, Brave, Opera и Яндекс Браузере — всего 138. Проверены связанные логины, дополнительный логин, поиск и пошаговый вход. Отдельно проверялось возвращение из окна подтверждения WinUp в перекрытую вкладку браузера.
- Подписанное Mozilla расширение Firefox 1.6.7 остаётся установленным после перезапуска. Сопряжение с WinUp сохраняется; проверка подписи Firefox включена.
- GitHub принял ключ WinUp в Chrome. Повторный вход прошёл в отдельном чистом профиле без пароля и прежней сессии. Учебный ключ удалён после проверки. Настройки 2FA не менялись.
- Сохранённая проверка Google подтверждает повторный вход ключом WinUp в чистом профиле на подписанной рабочей 1.15.3: сайт принял ответ и открыл аккаунт, пароль и код 2FA не вводились. Контрольная сумма приложения совпадает с выпуском; использовался собственный идентификатор WinUp. Эта проверка относится к 1.15.3. Пользователь дополнительно подтвердил создание ключей в GitHub и Google после установки 1.17.1.
- Инструкция: 57 изображений загружаются, внутренние ссылки и поиск по содержанию работают, семь адресов страниц расширений копируются, горизонтального переполнения в двух размерах страницы нет.
- В песочнице подключение системного провайдера Windows, вызов через COM, чтение статуса закрытой базы, отключение и повторное подключение прошли проверку.
- Дополнительно проверены 10 сценариев связанных логинов в списке расширения, поиске, распознавании существующей записи и пошаговом входе. До исправления восемь сценариев завершались ошибкой, после исправления проходят все десять.
- Вызовы системного кодировщика Windows проверены на ПК и в песочнице: пять проверок формата ответа, идентификатора ключа, выбранного пользователя и подписи выполнены независимым разборщиком CBOR и криптографическим проверяющим кодом Node.js. Воспроизведённый отказ регистрации 0x8007000D исправлен. Проверка включена в CI; отсутствие API и ответ E_NOTIMPL на серверной Windows отмечаются как пропуск с сохранением версии API и HRESULT, отдельно от успешного результата. Другие ошибки завершают проверку с отказом.
- На ПК создание ключа через системное окно Windows завершилось успешно. Независимый учебный сервер сверил идентификатор с базой WinUp и проверил ответ регистрации. Подмена этой проверки системным ключом Windows исключена сверкой идентификатора.
- В песочнице прошли 13 сценариев с настоящим списком ключей Windows: публикация при открытии базы, русские имена, повторное обновление, изменение имени, удаление, обработка дублей, очистка при блокировке и закрытии и восстановление списка после открытия базы. Запуск с закрытой базой очищает список, оставшийся от прежнего процесса. Другая папка WinUp не может перезаписать список подключённого провайдера. Пароли и закрытые ключи в передаваемых данных отсутствуют.

## Осталось

Повторный вход через системное окно Windows пока не подтверждён. Создание на ПК прошло; при входе Windows предлагала USB-ключ. Найдена и добавлена недостающая публикация списка ключей в Windows; её жизненный цикл проверен в песочнице. После исправления требуется повторить полный вход через Chrome на ПК: в Windows Sandbox отсутствует работающий TPM. Учебное подключение на ПК и временное доверие сертификату удалены, исходное состояние Windows восстановлено.

Проверка QR с телефоном не выполнена: на ПК нет Bluetooth. Успешный тест браузерного расширения этого ограничения не снимает.

Повторный вход ключом WinUp в Google на 1.18 отдельно не проверен. Сохранённый успешный тест 1.15.3 и создание ключа пользователем на 1.17.1 отмечены выше с указанием версий.

До завершения проверки системного провайдера выпуск 1.18.0 не помечен завершённым и не устанавливается поверх рабочей версии.
