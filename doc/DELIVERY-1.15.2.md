# WinUp 1.15.2 — скачанные файлы

Исправлен отказ при добавлении и переносе скачанных документов с отметкой Windows `Zone.Identifier`. Раньше WinUp запрещал любые дополнительные потоки NTFS, включая обычную отметку загрузки.

Теперь при добавлении файла WinUp удерживает его содержимое и отметку, сохраняет оба в шифрованном хранилище и проверяет записанные данные. Исходник при переносе удаляется после успешного завершения. Выгрузка через WinUp восстанавливает документ и отметку побайтно. Это действует также для файлов внутри папок и после повторного открытия хранилища.

Произвольные дополнительные потоки NTFS пока не поддерживаются: перенос останавливается, исходник остаётся. Копирование через подключённый диск Проводника не восстанавливает сохранённую WinUp отметку; используйте выгрузку через WinUp. Служебные записи не показываются в списке файлов приложения.

В Windows Sandbox прошли 197 обычных функциональных проверок без ошибок. Для исправления отдельно проверены точные байты документа и отметки после копирования/переноса, вложенные файлы, повторное открытие, повторное добавление после удаления через Проводник и 12 циклов записи/закрытия настоящего диска WinFsp.

Формат Cryptomator и его криптографические библиотеки не менялись. Приложение и файловый адаптер поставляются согласованным комплектом API 5; старый адаптер нельзя смешивать с новой программой. Браузерное расширение остаётся 1.6.6, подписанный Firefox не менялся.

Статус Google-passkey и аппаратных проверок приводится отдельно в локальном отчёте владельца. Новый аудит безопасности остаётся отложенным.
