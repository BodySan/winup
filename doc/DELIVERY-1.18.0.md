# Изменения WinUp 1.18.0

Подготовлены следующие возможности:

- Автоввод в приложения: порядок полей, паузы, правила для разных окон и горячая клавиша. При смене окна, блокировке базы или изменении записи ввод прекращается.
- Вложенные группы и несколько меток для поиска аккаунтов.
- Небольшие вложения в зашифрованных записях: до 2 МБ на файл и 16 МБ на запись. Вложения сохраняются в истории записи.
- Общий логин или пароль для связанных записей. При копировании и входе используется текущее значение основной записи.
- Объединение копий одной базы KDBX с выбором версий при конфликте. Перед объединением создаётся зашифрованный резерв.
- Исправление повреждений отдельной копии файлового хранилища средствами Cryptomator. Оригинал сохраняется; результат проверяется повторной диагностикой.
- Подключение WinUp к системному окну ключей доступа Windows. Завершающая проверка создания и входа на устройстве с TPM ещё требуется.

Инструкция дополнена порядком работы, ограничениями и снимками новых окон. Исправлены отображение размера небольших вложений, передача команд файловым модулям и отказ расширения при перекрытии браузера окном WinUp.

Связанный логин отображается в списке и участвует в поиске. При импорте дубли ищутся также по связанному логину и дополнительному логину. Если ссылка в существующей записи больше не работает, список показывает это, соответствующая строка импорта требует выбора, а обработка остальных аккаунтов продолжается.

Это подготовленная версия. Точный результат выполненных и оставшихся проверок приведён в [отчёте](ACCEPTANCE-1.18.0.md).

Исправлено использование связанных логинов в расширении: поиск, выбор аккаунта, распознавание существующей записи при сохранении и пошаговый вход используют действующие значения. Исправлены подключение провайдера из PowerShell и формат ответа создания ключа, который Windows отклоняла.

Добавлено обновление списка ключей для выбора в Windows: открытие и сохранение базы публикуют имена аккаунтов, блокировка и закрытие убирают их. Закрытые ключи и пароли в Windows не передаются. Создание через системное окно подтверждено на ПК; повторный вход после исправления списка ещё требует проверки.
