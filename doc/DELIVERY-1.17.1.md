# WinUp 1.17.1

Исправлена ошибка создания ключей доступа: окно подтверждения WinUp могло закрыть вкладку браузера, после чего сайт получал отмену операции, хотя ключ уже появлялся в базе.

После подтверждения вернитесь во вкладку сайта. Расширение передаст результат, когда она снова получит фокус. Отмена запроса и переход на другую страницу продолжают прерывать операцию.

Расширение обновлено до 1.6.7. Пакет Firefox подписан Mozilla и сохраняется после перезапуска браузера. При сборке проверяется совпадение подписанного пакета с текущими исходниками расширения.

Создание ключа и вход проверены на GitHub в Chrome с отдельной учебной базой. Повторный вход выполнен в чистом профиле без прежней сессии. Учебный ключ удалён после проверки; настройки 2FA не менялись.

Расширение проверено также в Edge, Firefox, Brave, Opera и Яндекс Браузере: заполнение паролей и 2FA, сохранение пароля, пошаговый вход, создание и использование ключей доступа, отмена и заблокированная база.

Для обновления замените закрытый WinUp вместе с файлом подписи. После запуска обновите расширение через меню WinUp. Firefox использует новый подписанный пакет; в Chromium обновите распакованное расширение на странице управления расширениями.
