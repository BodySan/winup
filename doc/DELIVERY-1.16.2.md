# WinUp 1.16.2 — изменения

- Во вкладке «Файлы» добавлена кнопка **«Без WinUp…»**. Памятка объясняет открытие отдельного пакета через официальный age и хранилища через Cryptomator. Её можно скопировать или сохранить в TXT. Новый пакет получает памятку рядом с собой; пароль туда не записывается. Старые файлы совместимы с теми же инструментами.
- Кнопки всех восьми вкладок собраны в группы по назначению. При небольшом размере окна действия прокручиваются, список остаётся доступным; переход клавишей Tab выводит кнопку в видимую область.
- В «Паролях» добавлена **«Проверить адреса…»**: проверка уже сохранённых сайтов, страниц входа, выбранных браузеров и путей к приложениям. Исправления сначала показаны в списке и применяются по галочкам. Полные адреса видны снизу. Есть редактирование записи и отдельная проверка доступности выделенных сайтов без отправки паролей.
- Исправлено сопоставление правил входа с сохранённым адресом сервиса авторизации. Например, запись Steam с `steamcommunity.com` теперь получает правила Steam, а не общую форму сайта. Пользовательские допустимые маршруты остаются прежними.
- Дубли Google/YouTube и Apple/iCloud распознаются между известными адресами этих сервисов. Например, запись с `www.google.com` сопоставляется с импортом `accounts.google.com`. Похожие чужие домены, необычные порты и другой логин не объединяются. Проверка адресов больше не предупреждает о неверном домене для сайта, уже разрешённого правилами сервиса.
- Импорт Google/Apple ищет дубли в базе и внутри CSV, в том числе по дополнительному логину. Повторный импорт не добавляет те же записи. Другой пароль требует выбора; совпадающий пароль с новыми заметками или 2FA больше не пропускается незаметно. Существующие записи не перезаписываются.
- Инструкция обновлена: 37 учебных снимков, восстановление без WinUp, проверка адресов и поведение дублей при импорте. Отдельная памятка — «Как открыть без WinUp.txt».

Проверено в Windows Sandbox: 212 общих функциональных проверок, 72 сценария файлов/импорта/блокировок, 136 положений кнопок во всех вкладках при двух размерах окна, а также действия через реальный интерфейс. Пакет расшифрован опубликованным age 1.3.2 и распакован tar Windows. Хранилище прочитано неизменённым официальным Cryptomator CLI 0.6.2. Текстовые и двоичные файлы совпали с оригиналами по SHA-256.

Проверены 168 публичных адресов встроенных правил. HTTP-ответ не подтверждает успешный вход: формы JavaScript, CAPTCHA, SMS и подтверждение владельца проверяются отдельно. `t2.ru/lk` вернул 503; адрес по такому ответу не менялся. Проверка личных записей выполняется кнопкой после открытия вашей базы; пароли в сторонние сервисы проверки не отправляются.

Криптографические форматы и библиотеки не менялись. Новый аудит безопасности остаётся отложенным. Подробности и границы функциональной приёмки: USABILITY-1.16.1.md.
