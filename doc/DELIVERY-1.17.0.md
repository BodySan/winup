# WinUp 1.17.0 — готовые функции записей и файлов

## Изменения

1. **История записей.** Изменение пароля, 2FA, passkey или дополнительных полей сохраняет предыдущее состояние в штатной истории KeePass. Можно посмотреть и восстановить версию одной записи. Более новое состояние остаётся в истории. Сохранение без изменений не создаёт лишнюю версию.
2. **Корзина.** Обычное удаление пароля, 2FA и passkey перемещает их в зашифрованную корзину KDBX. Можно восстановить запись вместе с историей и доступными связанными секретами либо окончательно удалить из текущей базы. Старые резервные копии сохраняют прежние данные.
3. **Пароль и восстановление файлового хранилища.** Во вкладке «Файлы → Ещё…» доступны смена пароля, получение стандартного ключа Cryptomator из 44 слов и задание нового пароля по этому ключу. Сначала закрывается открытое хранилище. Прежний зашифрованный masterkey сохраняется рядом; новый файл проверяется до атомарной замены. Файлы заново не шифруются.
4. **Диагностика файлового хранилища.** Штатные HealthCheck CryptoFS проверяют структуру и показывают итоговые счётчики и подробности. Отчёт можно скопировать или сохранить. Автоматического ремонта нет; содержимое каждого документа эта проверка не проверяет.
5. **Дополнительные защищённые поля.** В записи можно хранить именованные секреты, смотреть, редактировать, копировать и удалять их. Значения в списке скрыты, копирование очищается через 30 секунд. «Отмена» сохраняет исходный список. Поля входят в KDBX, читаемый текст и таблицу экспорта.
6. **Массовое изменение.** Для отмеченных паролей можно менять категорию, браузер, задержку приложения, закрепление и нажатие Enter. Меняются только выбранные параметры. Логины и пароли сохраняются; прежние состояния остаются в истории.
7. **Расширенный импорт.** Google/Apple CSV, Bitwarden JSON/CSV, 1Password 1PUX/CSV, LastPass CSV и произвольный CSV с выбором столбцов и разделителя. Есть просмотр новых записей, пропусков и дублей; исходные записи не перезаписываются. Переносятся поддерживаемые 2FA, категории, закрепление и дополнительные поля. Сайт выбирается среди адресов записи даже при наличии мобильного URI первым.

Все перечисленные функции доступны через интерфейс. Инструкция содержит маршруты к кнопкам и новые снимки учебной копии. Само наличие API библиотеки не считается готовой функцией.

## Проверки

- 117 функциональных сценариев в Windows Sandbox, без отказов: история/корзина после блокировки и повторного открытия; связь пароля с 2FA/passkey; окончательное удаление; стандартный ключ, смена и сброс пароля; сохранность файлов; отказ чужому ключу; диагностика повреждённой структуры без ремонта; реальные форматы импорта, дубли, дополнительные поля и экспорт; отказ сохранения с одновременной блокировкой базы.
- Регрессии прежних функций: `TOTAL failures=0`.
- 146 размещений действий доступны во всех восьми вкладках при размерах окна 700×550 и 1080×760.
- Независимая сверка 200 случайных ключей с **неизменёнными** RecoveryKeyFactory/WordEncoder Cryptomator 1.19.3: полное совпадение, проверка и обратное чтение.
- Пользовательские сценарии через настоящие окна и кнопки учебной копии: добавление/изменение/отмена удаления поля, копирование, массовая категория, просмотр/восстановление истории, удаление/восстановление из корзины, ключ восстановления, смена/сброс пароля, диагностика и импорт.

## Практические ограничения

- История начинает накапливаться с изменений в этой версии; прошедшие изменения не восстанавливаются задним числом. Действуют штатные ограничения истории KeePass.
- Импорт паролей не переносит вложения, passkey и историю другого менеджера. Неподдерживаемые записи и предупреждения видны перед импортом. Экспорт исходного менеджера содержит открытые секреты и остаётся на диске.
- Восстановление локального passkey не возвращает регистрацию, удалённую на сайте.
- Ключ восстановления Cryptomator остаётся действительным после смены пароля. Старые копии masterkey и резервные хранилища используют старый пароль. Пароль отдельного пакета age этими командами не меняется.
- Диагностика структуры не доказывает целостность содержимого каждого документа. Отложенный аудит безопасности не проводился.

Пункты списка «потом» остаются отложенными: расширенный Auto-Type, системный поставщик passkey Windows, слияние/синхронизация баз, теги/дерево групп, вложения, ссылки на поля и автоматический ремонт хранилища.
