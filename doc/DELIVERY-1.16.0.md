# WinUp 1.16.0 — файлы и порядок в аккаунтах

## Пароли и шаблоны

- Закрепление записей: отмечены ★, идут первыми; есть фильтр «Только закреплённые».
- Поиск по названию, сайту, основному и дополнительному логину; совместные фильтры по типу и категории, сброс одним нажатием.
- 135 встроенных шаблонов распределены по 15 категориям: игры, дом, еда, покупки, поездки, финансы, работа, учёба, почта и облако, общение, видео и музыка, нейросети, связь, госуслуги, другое. У записи можно указать свою категорию.
- При выборе шаблона видны уже сохранённые аккаунты сервиса. Совпадение введённого логина выделяется; существующие записи не заменяются.
- Импорт CSV Google Password Manager и Apple Passwords с предпросмотром. Точные повторы пропускаются; другой пароль существующего аккаунта требует выбора и сохраняется отдельной записью. Пароли в предпросмотре скрыты. Поддерживается OTPAuth, если это поле присутствует в экспорте Apple. Passkey таким CSV не переносится.

## Файлы

- «Зашифровать файлы…» и «Зашифровать папку…» создают отдельный стандартный пакет tar.age с независимым паролем. Хранилище и WinFsp для этого не нужны.
- «Расшифровать пакет…» создаёт новую обычную папку; существующие данные не заменяются. Затем можно добавить результат в открытое хранилище.
- «Выгрузить…» передаёт только выделенные файлы и папки: зашифрованным пакетом либо обычной копией. Для этой команды нужен подключённый диск WinFsp.
- Добавление в хранилище явно предлагает копирование или перенос. По умолчанию исходники сохраняются. Для удаления исходников сначала полностью проверяется записанная копия.
- История хранит зашифрованные версии с ограничением числа и размера. Восстановление создаёт новую копию, включая ранее удалённый файл, если он был в снимке.
- «Резерв / перенос…» копирует всё закрытое хранилище с историей, сверяет состав и контрольные суммы. Копию можно открыть на другом ПК прежним паролем.
- Настройки хранилища: постоянная буква диска, режим чтения, лимит истории, резерв перед открытием, редактор и отдельный срок закрытия проекта. В меню есть копирование пути диска и запуск редактора.
- Занятый файл мешает безопасному отключению: WinUp объясняет причину и оставляет диск доступным.

## Блокировка и инструкция

Исправлены ошибки, найденные в пользовательских сценариях: отдельное шифрование при открытом хранилище, двойное расширение имени пакета, длинные пути резервных копий, отключение диска после отказа записи в режиме чтения и обновление уже удалённого значка трея при выходе.

«Заблокировать базу» закрывает пароли, 2FA и ключи доступа вместе, сохраняя открытый файловый проект. «Заблокировать хранилище» закрывает только файлы. «Заблокировать всё» и Ctrl+L закрывают оба раздела.

Инструкция дополнена новыми действиями и актуальными учебными снимками. В ней объясняются перенос на другой ПК, доступ редактора и ИИ, ограничения истории и независимые пароли пакетов.

## Практические ограничения

CSV экспорта Google/Apple содержит открытые пароли. После успешного импорта и проверки удалите его самостоятельно. 2FA переносится только при наличии поддерживаемого секрета в CSV; ключи доступа не импортируются таким способом.

История не сохраняет каждое изменение в стороннем редакторе. Для важных промежуточных этапов снимайте версию вручную. История на том же диске не заменяет внешний резерв; автоматические резервные папки сами не удаляются.

Для Проводника и выгрузки выделенного нужен WinFsp. Самостоятельные пакеты, добавление через WinUp, резерв и одиночная обычная выгрузка двойным щелчком работают без диска.

Открытый диск доступен программам с соответствующими правами Windows. Для проекта с ИИ создавайте отдельное хранилище с нужными материалами. Это не отдельная песочница для редактора или ИИ.

Пароль пакета или файлового хранилища не восстанавливается кодом восстановления базы паролей. Формат хранилища остаётся Cryptomator 8, криптографические библиотеки Cryptomator и age не изменялись. Новый аудит безопасности остаётся отложенным.

## Приёмка

Результаты финального прогона фиксируются в FILE-WORKFLOWS-1.16.md перед выпуском. Версия требует нового WinUp.exe: старое приложение 1.15.x не принимает комплект API 6.
