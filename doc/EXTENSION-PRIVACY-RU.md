# Расширение WinUp: обработка данных

Расширение передаёт выбранному локальному приложению WinUp адрес страницы, имя аккаунта и данные, необходимые для запрошенного входа, создания ключа доступа или сохранения пароля. Передача выполняется через Native Messaging на том же компьютере. Мастер-пароль базы не передаётся расширению.

Расширение не отправляет базу, пароли и историю посещений разработчику, в GitHub или на сервер аналитики. При заполнении формы сайт получает введённые данные обычным способом; это сайт, который пользователь выбрал для входа.

Для двухэтапной формы имя аккаунта временно сохраняется в памяти расширения до трёх минут. Введённый и отправленный пользователем пароль может находиться в памяти до 60 секунд, чтобы предложить сохранение после перехода страницы. Эти данные привязаны к вкладке и точному адресу сервера; они не записываются в браузерное хранилище и удаляются при смене сервера, закрытии вкладки, отказе или сохранении. Остановка фонового процесса браузера также удаляет их.

Пароль сохраняется в базе только после нажатия кнопки в расширении и подтверждения редактора записи в WinUp. Можно отказать в сохранении, отключить расширение или разорвать его сопряжение в WinUp. Удаление расширения удаляет его локальный токен сопряжения и настройки; база WinUp остаётся в выбранной пользователем папке.

Декларация Firefox описывает передачу данных локальному приложению: `authenticationInfo` и `browsingActivity`. Это не разрешение передавать данные на сервер разработчика. Требования Mozilla: https://extensionworkshop.com/documentation/publish/add-on-policies/ .
