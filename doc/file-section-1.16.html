21. Шифрованные файлы и папки

Для вкладки «Файлы» открывать базу паролей не нужно. Есть два способа работы:

  • Хранилище Cryptomator — папка с зашифрованными данными. Открываете её паролем, подключаете диск и работаете с файлами в Проводнике или редакторе.
  • Отдельный пакет tar.age — зашифрованный файл для передачи или хранения. Его пароль независим от пароля хранилища; для работы пакет сначала расшифровывается в новую обычную папку.

Создать и наполнить хранилище

  1. Нажмите «Создать хранилище», выберите новое имя папки и отдельный длинный пароль. Уже существующую папку подключайте через «Добавить существующее», затем «Открыть».
  2. Используйте «Добавить файлы», «Добавить папку» или перетаскивание в список. Выберите «Копировать», чтобы исходники остались обычными, либо «Перенести», чтобы удалить их после чтения и проверки зашифрованной копии. По умолчанию выбрано копирование.
  3. «Новая папка» создаёт папку внутри хранилища. Двойной щелчок по папке открывает её; по файлу — предлагает сохранить обычную копию. «Назад» возвращает на уровень выше.
  4. «В Проводнике» подключает диск. Для него нужен WinFsp; при первой установке Windows запросит права администратора. Добавление через WinUp, резервирование и отдельное шифрование не требуют драйвера.
  5. После работы сохраните документы и закройте их в редакторах. Нажмите «Заблокировать хранилище». Если файл занят, WinUp оставит диск доступным и объяснит, что закрыть.

Копирование оставляет обычные исходники на прежнем месте. При переносе выполняется обычное удаление: старые резервные копии и следы на накопителе могут сохраниться. Метка загрузки Windows Zone.Identifier переносится; другие дополнительные потоки NTFS пока не поддерживаются, и исходник с ними сохраняется.

Зашифровать уже существующие файлы отдельно

  1. «Зашифровать файлы…» или «Зашифровать папку…» → выберите исходники.
  2. Укажите имя Пакет.tar.age и новый пароль. Исходники остаются на месте. Для переноса явно отметьте «Удалить исходники после проверки пакета».
  3. WinUp шифрует и полностью читает пакет обратно. Исходники удаляются только после успешной проверки. Существующий пакет не заменяется.

На другом ПК: «Расшифровать пакет…» → файл → родительская папка → название новой папки → пароль. Уже существующие данные не заменяются. Если открыто хранилище, WinUp предложит добавить туда результат; обычная папка до такого переноса остаётся доступной без пароля.

Пакет имеет стандартный формат age с обычным tar внутри; его можно расшифровать совместимым age. Драйвер и база паролей для пакетов не нужны. «Ещё… → Проверить пакет» проверяет его без извлечения файлов.

Выгрузить часть хранилища

Выделите файлы или папки и нажмите «Выгрузить…». По умолчанию выбран зашифрованный пакет с отдельным паролем. В него попадёт только выделенное, остальные данные хранилища не передаются. Другой вариант — обычная копия, доступная без пароля. Для этой команды используется подключённый диск и WinFsp; WinUp предложит подключение. Одиночный файл можно сохранить обычной копией двойным щелчком без диска.

История, удаление и восстановление

История включена по умолчанию: до 10 версий и 1024 МиБ. Снимки сохраняются внутри зашифрованного хранилища перед изменениями через WinUp, перед подключением диска и после его безопасного отключения. Неизменившееся содержимое не дублируется.

«Ещё… → Снять версию сейчас» сохраняет текущий снимок и отключает диск. Для продолжения нажмите «В Проводнике». История не записывает каждое сохранение в стороннем редакторе: для важных промежуточных этапов снимайте версию вручную.

«История файлов…» → выберите дату и файл → задайте новое имя → «Восстановить». Получится новая копия в хранилище. Так можно вернуть файл, удалённый через WinUp или Проводник, если он есть в сохранённом снимке. Старейшие версии удаляются при превышении лимита. Если одна версия больше лимита, WinUp объяснит ошибку; лимит меняется в настройках.

«Ещё… → Удалить выбранное» удаляет выделенные данные; при включённой истории перед удалением сохраняется снимок. История находится на том же накопителе и не заменяет внешний резерв.

Резерв и перенос всего хранилища

  1. «Резерв / перенос…» сначала безопасно закрывает хранилище, затем копирует всю зашифрованную папку, включая историю, и сверяет контрольные суммы.
  2. Передайте полученную папку целиком на другое устройство. Не выбирайте только masterkey.cryptomator или отдельные файлы из d.
  3. На другом ПК: WinUp → Файлы → «Добавить существующее» → папка копии → «Открыть» → прежний пароль. Для Проводника установите WinFsp.

«Ещё… → Проверить резерв» сверяет состав и контрольные суммы. Для проверки пароля и фактического восстановления откройте копию как отдельное хранилище и прочитайте нужный файл. В настройках можно включить резерв перед каждым открытием и выбрать отдельный накопитель. Эти резервные папки автоматически не удаляются.

Пароль файлового хранилища и пароль пакета не восстанавливаются кодом восстановления базы паролей. Архив переноса WinUp не включает внешние хранилища: переносите их отдельной командой. Настройки буквы диска и редактора задаются заново на другом ПК.

Проект, редактор, ИИ и режим чтения

«Ещё… → Настройки хранилища / проекта»: выберите постоянную свободную букву диска, редактор, лимит истории и срок закрытия проекта. Режим «Только для чтения» запрещает изменения через WinUp и подключённый диск; переключение применяется после повторного открытия.

Для проекта с ИИ создайте отдельное хранилище, положите туда только нужные материалы и подключите диск. «Скопировать путь проекта» копирует путь корня подключённого диска; «Открыть проект в редакторе» запускает выбранный EXE с этим путём. Укажите этот каталог инструменту ИИ. Его доступ зависит от выбранного проекта и разрешений инструмента.

Пока диск открыт, файлы доступны программам с соответствующими правами Windows, включая редактор и ИИ. Другая закрытая база или закрытое файловое хранилище не становятся доступными от указания пути проекта. Отдельное хранилище ограничивает объём открытых данных; это не изоляция от программ, уже имеющих доступ к открытым дискам.

В режиме проекта пароли закрываются по общему таймеру, проект — по отдельному. Кнопка «Заблокировать базу» закрывает пароли, 2FA и ключи доступа вместе, сохраняя файловый диск. «Заблокировать хранилище» закрывает только файлы. «Заблокировать всё» и Ctrl+L закрывают оба; при занятом файле диск остаётся открытым с объяснением.

Основное хранилище использует оригинальный формат Cryptomator 8 и может открываться совместимым Cryptomator. Криптографические библиотеки Cryptomator и age не изменялись. Новые функции прошли функциональные проверки; отложенный аудит безопасности ими не заменяется.
