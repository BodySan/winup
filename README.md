# WinUp

WinUp объединяет менеджер паролей, шифрованные файлы и работу с программами в одном приложении для Windows. Интерфейс на русском языке. Программа помогает установить нужные приложения и войти в сохранённые аккаунты.

## Возможности

- Хранение паролей, дополнительных логинов, резервных кодов и других секретов в базе KDBX.
- Коды 2FA и ключи доступа для входа без пароля.
- Расширение для Chrome, Edge, Firefox, Яндекса, Brave и Opera: заполнение форм, предложение сохранить пароль и работа с ключами доступа.
- Файловые хранилища Cryptomator: открытие в Проводнике, история файлов, резервные копии и настройки проектов.
- Отдельное шифрование файлов и папок для передачи. Пакеты можно открыть через age, а хранилища — через Cryptomator, даже без WinUp.
- Установка программ из WinGet или своих установщиков, запуск переносных приложений и сохранённые ссылки на загрузку.

В версии **1.17.1** исправлена ошибка создания ключа доступа, возникавшая, когда окно WinUp закрывало вкладку браузера. Расширение Firefox обновлено и подписано Mozilla. [Список изменений](doc/DELIVERY-1.17.1.md).

## Начало работы

1. Скачайте приложение из [последнего выпуска](https://github.com/BodySan/winup/releases/latest). Сохраните `WinUp.exe` и его подпись `WinUp.exe.sig` в одной папке.
2. Запустите WinUp. Мастер поможет создать базу паролей и добавить программы.
3. Для заполнения паролей в браузере подключите расширение через меню WinUp.
4. Для работы с файлами создайте хранилище во вкладке «Файлы». Для подключения его как диска нужен драйвер WinFsp.

Инструкция доступна в меню «Справка». Её отдельная HTML-копия входит в архив исходников `src.zip` и открывается без интернета.

Пароли импортируются из Google, Apple, Bitwarden, 1Password и LastPass. Для других CSV-файлов можно выбрать столбцы вручную. Перед сохранением WinUp показывает новые записи и дубли. Ключи доступа, вложения и история другого менеджера при импорте паролей не переносятся.

Автозаполнение зависит от формы входа на сайте. SMS, CAPTCHA и подтверждения аккаунта требуют вашего участия.

## Обновления

Чтобы обновить приложение, закройте WinUp и замените `WinUp.exe` вместе с подписью. Сохраните папки `data`, `apps` и свои файловые хранилища.

Компоненты обновляются через меню «Обновления компонентов»: загрузите готовый комплект с GitHub или выберите полученный файл `.wup`, затем перезапустите WinUp. KeePass и WinFsp обновляются отдельными кнопками.

WinUp проверяет подпись и совместимость комплекта перед установкой. Ключ подписи выпусков хранится на ПК владельца. GitHub хранит выпуски и выполняет автоматические проверки; база пользователя туда не отправляется.

При самостоятельной проверке `WinUp.exe` используйте уже доверенную копию `tools/verify-app.ps1` и публичного ключа. Подробнее: [обновления и проверка файлов](doc/UPDATES-SIMPLE-RU.md).

## Сборка

Основное приложение собирается в Windows с .NET Framework 4.x:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File src/build.ps1
```

Готовые криптографические компоненты входят в исходный комплект. Для пересборки адаптера ключей доступа нужен .NET SDK 8.0.425, файлового адаптера — JDK 24, помощника пакетов — Go 1.27.2.

Функциональные проверки запускаются в отдельной Windows Sandbox или одноразовом Windows runner:

```powershell
./qa/security/ci.ps1 -FunctionalOnly
```

Описание компонентов и их лицензий: [THIRD-PARTY.md](src/THIRD-PARTY.md). WinUp распространяется по GPL-3.0-or-later, файловый адаптер — по AGPL-3.0.
