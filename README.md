# WinUp

Переносное приложение для Windows с русским интерфейсом: установка выбранных программ, база паролей KDBX, 2FA, файловые хранилища Cryptomator и собственное расширение для Chromium-браузеров и Firefox. Для личного использования.

В версии 1.17.0: история и корзина записей, защищённые дополнительные поля, массовое редактирование, импорт Bitwarden/1Password/LastPass и своего CSV, смена/восстановление пароля файлового хранилища стандартным ключом Cryptomator и диагностика CryptoFS. Всё подключено к интерфейсу. Подробнее: [изменения 1.17.0](doc/DELIVERY-1.17.0.md).

Готовое приложение и подписанные комплекты: [Releases](https://github.com/BodySan/winup/releases).

При ручной замене приложения скачайте `WinUp.exe` и `WinUp.exe.sig`, затем проверьте файл **уже имеющейся доверенной копией** `tools/verify-app.ps1`. Проверка использует локальный публичный ключ. Новый проверяющий скрипт и новый ключ из того же непроверенного источника не защищают от его взлома.

## Обновления простыми словами

| Вариант | Что делать | Когда удобен |
|---|---|---|
| Новое приложение целиком | Закрыть WinUp и заменить `WinUp.exe`. Папку `data` сохранить. | Минимум настройки, обновление всей программы. |
| Пакет из файла | Меню → Обновления компонентов → Установить из файла; выбрать `.wup`, затем перезапустить. | Можно передать брату один файл, интернет ему не нужен. |
| Пакет с GitHub | Меню → Обновления компонентов → Проверить → Скачать комплект → Перезапустить. | Меньше постоянных действий, файл искать не надо. |
| KeePass и WinFsp отдельно | Нажать соответствующую кнопку в окне обновлений. | Проверенные официальные выпуски этих компонентов. |

Сетевой источник уже указан в программе. Его можно изменить или отключить пустым адресом. Автоматической установки без нажатия кнопки нет.

GitHub Actions раз в неделю проверяет новые стабильные версии Bouncy Castle, CBOR, Numbers и Public Suffix List; пересобирает адаптер и запускает проверки. При успехе сохраняет проверенный кандидат. При ошибке выпуск прекращается. Новая основная версия библиотеки требует проверки адаптера.

Ключ подписи остаётся на ПК владельца. После успешных тестов владелец запускает `tools/publish-tested.ps1`: скрипт скачивает кандидат, сверяет его исходники с доверенной локальной копией, повторно проверяет DLL по подписанным официальным NuGet-пакетам, воспроизводимо пересобирает адаптер и локально пересобирает приложение. Затем подписывает и публикует обновление. После этого на втором ПК достаточно кнопки в WinUp. Изменённый в GitHub собственный код без изменения доверенной локальной копии не будет подписан. Облачной подписи в настроенном workflow нет; добавление требует отдельного решения владельца.

`-Refresh` запускает свежий прогон и выпускает именно его кандидат; `-PrepareOnly` готовит файлы без публикации. Если официальный узел отдаёт устаревшую копию PSL, сохраняется более свежий доверенный встроенный список. Новый список сверяется с содержимым указанного коммита официального проекта PSL и его принадлежностью основной истории; понижение версии запрещено. Это устраняет сбой, когда разные CDN-узлы возвращают разные официальные снимки.

Cryptomator/Java остаются в согласованном runtime. Скрипт сообщает о новых CryptoFS/Cryptolib, но не подменяет отдельные JAR без пересборки и приёмки всего файлового модуля. Изменения собственного кода и несовместимые API автоматически не исправляются. Все автоматические проверки покрывают конкретные сценарии; они не доказывают отсутствие любых уязвимостей.

Для повседневных обновлений компонентов удобнее кнопка с GitHub. Для новой функции или изменения несовместимого API нужен новый `WinUp.exe`.

## Сборка

Windows и .NET Framework 4.x:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File src/build.ps1
```

Криптографические компоненты и исходники адаптеров включены. Для воспроизводимой пересборки адаптера ключей доступа нужен .NET SDK 8.0.425; файлового адаптера — JDK 24; помощника пакетов — Go 1.27.2. Зависимости age включены в vendor, пересборка помощника не требует их скачивания. Подробности и лицензии: [THIRD-PARTY.md](src/THIRD-PARTY.md).

Проверки выполняются только в изолированной Windows Sandbox или одноразовом Windows runner, с искусственными данными:

```powershell
./qa/security/ci.ps1 -FunctionalOnly
```

## Пакеты компонентов

Закреплённый в приложении публичный ключ проверяет подпись манифеста, затем размеры и SHA-256 всех файлов. Неполный, изменённый или несовместимый пакет отвергается. Установка готовит комплект к следующему запуску; текущий процесс использует один проверенный комплект. Предусмотрены откат и возврат к встроенным компонентам при повреждении пакета.

Закрытого ключа, паролей, баз пользователя и истории рабочего каталога в репозитории нет. Ключ выпусков на ПК защищён DPAPI текущего пользователя. Облачная подпись отключена. Защищённый файл ключа привязан к Windows-профилю: одна его копия не гарантирует восстановление после переустановки Windows. Откат не снижает максимальный принятый номер выпуска, поэтому сеть не может повторно установить отвергнутый пользователем старый выпуск. Для повторной установки после отката нужен следующий номер.

WinUp: GPL-3.0-or-later. Отдельный файловый адаптер: AGPL-3.0. Лицензии сторонних компонентов сохранены в исходном пакете.

Полная инструкция: [Инструкция.html](doc/Инструкция.html). Разъяснение вариантов выпуска и рисков: [Обновления простыми словами](doc/UPDATES-SIMPLE-RU.md). Для Firefox включён подписанный Mozilla пакет 1.6.6: постоянная установка через about:addons проверена с сохранением сопряжения после перезапуска. Временная установка через about:debugging по-прежнему исчезает после закрытия Firefox.
